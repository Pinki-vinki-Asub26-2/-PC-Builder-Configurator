# -PC-Builder-Configurator
В данном репозитории,я решаю задачу по созданию собственного конфигуратора комплектующих,для новичков в данной теме,ибо бывает много проблем с совместимостью комплектующих/(например:нехватка мощности БП,малый размер корпуса или перегрев.) (for example: insufficient power supply capacity, small case size, or overheating).
